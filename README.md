# CivicFix – AI Powered Civic Issue Reporting Platform 🚀

## 📌 Problem Statement
In many cities, citizens face daily civic issues such as:
- Garbage dumping
- Potholes
- Waterlogging
- Broken electricity wires
- Sewage overflow

However, existing complaint systems are often slow, non-transparent, and difficult to track. Citizens usually do not receive proper updates regarding their complaints.

---

# 💡 Solution – CivicFix

**CivicFix** is an AI-powered civic issue reporting platform that creates a transparent and intelligent bridge between citizens and municipal authorities.

The platform allows users to:
- Report civic issues easily
- Upload live images
- Detect location automatically
- Track complaint status in real-time
- Receive email notifications
- Ensure transparency using proof-based verification

---

# ✨ Key Features

## 👤 User Panel
- Upload civic issue with image
- Auto location detection using reverse geocoding
- Real-time complaint tracking
- Email notifications for every status update
- View complaint status:
  - Pending
  - In-Progress
  - Resolved
  - Escalated

---

# 🤖 AI-Powered Smart System
Our integrated AI module:
- Detects issue category from uploaded image
- Filters fake or irrelevant complaints
- Assigns severity-based priority
- Helps authorities focus on critical issues first

### Example:
- Exposed electric wire → High Priority
- Garbage issue → Medium Priority

---

# ⏳ Auto Escalation System
If any issue is not resolved within **7 days**, the system automatically escalates it to higher authorities using scheduled backend jobs (cron jobs).

This ensures:
- Faster resolution
- Better accountability
- Transparent governance

---

# 🛠️ Admin Panel
The admin dashboard allows authorities to:
- View all complaints
- Accept or reject issues
- Update complaint status
- Monitor escalated issues
- Download CSV reports

## 🔍 Proof-Based Resolution System
Before marking any issue as **Resolved**, the admin must upload a **live proof image** of the fixed issue.

The user then receives:
- A confirmation email
- Resolution proof image

The user can:
- ✅ Confirm issue resolved
- ❌ Reject resolution and upload feedback image

This creates a **two-way verification system** and ensures complete transparency.

---
